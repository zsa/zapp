- `zapp devices` shows the radio firmware version of each half and offers a newer release when one exists.
- New `zapp update radio` command downloads and installs the latest radio firmware.
- If a cable update stops early (error or Ctrl-C), zapp restarts both halves so the keyboard is usable again.
- While waiting for the right half, zapp reminds you to check the TRRS cable.
- Messages and help now call the keyboard Wireless Voyager.
